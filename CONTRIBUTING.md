# Contributing to VS Agent Bridge

Thank you for your interest in VS Agent Bridge.

## Pull requests

External pull requests are not accepted. All development and code changes are done by the author.
This keeps the whole code under one owner, so the author can grant separate licenses (see below).

## Issues

Bug reports and suggestions are welcome - please open an Issue. Discussion is welcome too, but decisions about
changes are made by the author.

A useful bug report includes:

- the bridge version (the name of the package, `VSAgentBridge-<version>.zip`);
- the Visual Studio version, and the agent with its version (`claude --version` or `opencode --version`);
- what you did, what you expected and what happened;
- the relevant lines from the bridge log (`Logs` next to `vsagentbridge.exe`).

Issues are public. Before posting log lines or screenshots, remove anything you cannot share: file paths, names
and code from your company's projects.
